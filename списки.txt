====================================Отношения между селекторами ===========================

Устанавливаются при помощи CSS комбинаторов, к которым относятся пробел, >, ~, +

> применяет стили к непосредственно вложенному элементу разметки, например: 
div > p 
{
	набор стилей будет применён к тем элементам <p>, которые вложены в элемент <div>
	----------------------------------------------------------------------------------
	<div>
		<p>применение</p>
			<article>
				<p>Здесь уже не применяется, по-скольку нет непосредственного вложения в '<div>' </p>
			<article/>
	</div>
	----------------------------------------------------------------------------------
}

div p
{
	набор стилей будет применён к тем элементам <p>, которые вложены в элемент <div> на любом уровне глубины	
}

div + p
{
	набор стилей будет применён к тем элементам <p>, которые следуют за элементом <div> на одной глубине	
}

div ~ p
{
	набор стилей будет применён к тем элементам <p>, которые следуют за элементом <div> на любом уровне глубины	
}
}
